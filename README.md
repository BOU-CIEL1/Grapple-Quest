# Grapple-Quest
![Status](https://img.shields.io/badge/Status-Not%20Started-red)

## Description courte
Jeu de plateformer 2D en binome avec @Maisan18 pour un projet de jeu Unity pour la licence pro Level Design de Gamagora (Lyon 2).

## Histoire/Lore
Vous êtes un petit lutin qui s'est fait volé son trésor par une infâme bête, tout ce qu'il vous reste c'est une épée rouillée et votre fidèle grappin.
Le but est de progresser dans les niveaux afin de combattre le boss et reprendre vos biens.

## Fonctionnalités
- Mécanique principale: Utilisation d'un grappin dans les niveaux.
- Attaque avec épée.
- Le joueur peut récupérer de l'énergie en tuant les ennemis et peut l'utiliser pour regagner un point de vie.
- Le joueur peut récupérer des pièces d'or sur son chemin (sert pas à grand chose pour le moment à part pour le lore)
- Différents ennemis (ex: une vache qui balance du caca)

## Inspirations
- Link: The Faces of Evil
  - Chara design du personnage principal (simili-Link)
  - Le seul Zelda en plateformer à ce jour
  - C'est drôle
- Super Mario Bros
  - Les bases du jeu de plateforme
  - Possibilité de récupérer des pièces sur le parcours
- Hollow Knight
  - Mécanique de récupérer de la vie grâce à l'énergie accumulée en tuant des monstres
- Wario Land (techniquement juste Wario mais bon...)
  - Motivation (récupérer son argent) et caractère du personnage principal.
